## Что не следует выдавать за готовое

- Демо не принимает реальные платежи и не должен собирать номера карт.
- Выбор даты и времени пока является пожеланием клиента, а не проверкой доступности команды.
- Запрос закрытия аккаунта не является автоматическим удалением.
- Общий тёмный слой не равен полной переработке каждого рабочего экрана.
