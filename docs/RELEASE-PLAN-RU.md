# Выпуск для продажи

Согласованный объём: безопасная поставка и установка; клиенты/объекты; календарь и повторяющиеся задания; уведомления; документация и материалы для продажи. Сначала отдельная установка для одной компании. Без оплаты, зарплат, GPS, чата и общей базы нескольких компаний.

Критерии выпуска:

- Установочный архив собирается по разрешённому списку; нет базы, паролей, ключей и фотографий пользователей.
- Новая установка получает собственные пароль и секрет. Ключи не показываются в журнале.
- Копия базы и фотографий восстанавливается в новую пустую папку; рабочая база не перезаписывается.
- Обновление существующей базы сохраняет прежние задания, отчёты и изображения.
- Объект выбирается из справочника; изменение карточки не меняет исторические сведения задания.
- Повторяемость имеет явную дату окончания, защиту от дублей, исключения, перенос одного посещения и отмену будущих незапущенных посещений.
- Календарь и проверки пересечений используют Europe/Berlin; ошибочные/неоднозначные часы перевода времени не принимаются молча.
- Сотрудник получает только свои уведомления. Реальная отправка писем требует настроенного провайдера; демонстрация не отправляет письма.
- Проверки API и браузера проходят, платные ресурсы не создаются, сторонним фирмам сообщения не отправляются.

Продажи: подготовить описание, снимки и условия поддержки; сначала проверить действующий приём продавцов на выбранной площадке. Доступ к аккаунту, публикация платного объявления и покупка рекламы не считаются выполненными разработкой.

## Реализовано в кандидате 2.1

- Новый приватный установщик, сборка по разрешённому списку, SHA-256, отдельная команда диагностики и Docker Compose с постоянным томом.
- Восстановление в новую папку с проверкой базы и обоих наборов изображений; миграция старой схемы проверяется без удаления старых заданий.
- Клиенты/объекты, поиск и страницы, исторические снимки в заданиях, история объекта.
- Календарь неделя/месяц, серии с конечной датой, перенос отдельного задания, предупреждение о пересечениях перед сохранением, отмена будущих незапущенных заданий.
- Личный ящик уведомлений сотрудника; необязательная очередь email с повтором. В демо реальные письма заблокированы.
- Переключение элементов интерфейса DE/EN, без изменения пользовательских данных; руководства и описания товара DE/EN.
- Генератор скриншотов на отдельной вымышленной установке.

Внешние шаги не выполнены разработкой: подтверждённая доставка настоящего письма, постоянное производственное размещение с внешними копиями, реквизиты/документы продавца, окончательная цена/лицензия и аккаунт/проверка площадки. Это не обещание завершённой коммерческой эксплуатации или гарантированных продаж.
