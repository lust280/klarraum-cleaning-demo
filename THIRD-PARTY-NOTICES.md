# Third-party components

Klarraum uses Node.js (including SQLite) and the `sharp` package with its native image-processing dependencies. Browser tests use Playwright. These dependencies are not owned by the seller and their licenses remain applicable. Refer to each installed package's LICENSE/NOTICE files and sharp's third-party libvips notices. Do not remove them when distributing binaries or dependencies.

The release archive ships source and package-lock.json, not node_modules or a Node binary. `npm ci` downloads the pinned dependencies. The dependency license inventory is generated by `npm run licenses` after installation. Verify the inventory and the notices of native components before shipping a container or bundled binary. This document is not a claim that all dependencies have been independently legally audited.

Public fonts use the visitor's system fonts. Original illustrative CSS and fictional examples are included; customer logos, photographs and statements are not part of a transferable stock-image license.
